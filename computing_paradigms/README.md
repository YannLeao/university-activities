# Computing Paradigms

This folder contains the activities developed during the **Computing Paradigms** course, taught by 
Professor Gabriel Denini.

Each activity explores fundamental concepts from different programming paradigms, with a practical focus on small 
programs and exercises.

## Repository Organization

The activities are organized into separate folders. Each one contains:

- The corresponding **source code files**
- A dedicated **README** with explanations, execution instructions, and additional comments

## Content

### 1. [Activity 1 — Interactive SQL in PostgreSQL](activity_1)

Implementation of five proposed exercises using a less conventional language. In this case, **SQL**, using the `psql` 
client from PostgreSQL to simulate user input.
