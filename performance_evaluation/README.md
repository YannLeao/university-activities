# Performance Evaluation

This folder contains projects developed for the **Performance Evaluation** course, taught by Professor Gabriel Denini.

The main focus of this course is analyzing algorithm efficiency, comparing strategies, and 
understanding computational cost.

## Content

### 0. [Activity 0 — Prime Numbers with Sieve of Eratosthenes](activity_0)

Implementation of a program in **C++** that:

- Reads an integer $N > 0$
- Validates user input
- Computes all prime numbers up to $N$
- Uses the **Sieve of Eratosthenes** for efficiency
- Displays the primes and their total count

The goal is to study performance and compare efficient strategies for prime number computation.

### 1. [Activity 1 — Arrays and Strings Exercises](activity_1)

Set of exercises focused on **arrays and strings**, covering fundamental operations such as:

- Aggregations (sum, product)
- Searching and counting
- Array manipulation (reverse, filtering)
- String processing (palindromes, character analysis)

The activity emphasizes problem-solving and serves as a foundation for later performance analysis.
Developed in collaboration with [Maria Clara](https://github.com/MClaraFerreira5)

### 3. [Activity 3 — Sorting Algorithm Comparison](activity_3)

Implementation of a program in **C++** that compares the performance of two sorting algorithms.

The program:

- Reads integers (including negative values) from a file `arq.txt`
- Stores the values in a suitable data structure (e.g., vector)
- Sorts the data using:
    - A **slow algorithm** (e.g., Bubble Sort, Insertion Sort)
    - A **fast algorithm** (e.g., Quick Sort, Merge Sort)
- Measures execution time for each algorithm
- Repeats each sorting process **five times**
- Computes and displays the **average execution time**
- Saves the sorted output to `arq-ordenado.txt`

The goal is to analyze and compare algorithm efficiency in practice, reinforcing concepts of computational cost and 
performance evaluation.
